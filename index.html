Fun discovery. The ticket machines in Barcelona still emit tickets with a magnetic strip. But, all the fare gates in Granollers have been replaced and now only accept NFC and barcodes. So if you have bought a return trip you suddenly can't get home. To get around this they have a set up a stand alone machine to validate tickets and leave the bypass gate open. Of course there is no signage so person after person tries to tap the magnetic strip ticket only for nothing to happen until eventually they find someone to ask what to do.

They found large scale battery installations as one major cause, but obviously this is true for any other computerized system that does cron jobs and has a synchronized clock. As weird as it sounds, adding random 0-59.999s delays to cron jobs in Linux distributions and other software would actually help the power grid.
